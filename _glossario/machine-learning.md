## Como funciona

Em vez de escrever regras ("se o cliente fizer X, então Y"), você mostra ao sistema muitos exemplos com o resultado conhecido. O modelo encontra os padrões e passa a aplicá-los em casos novos. Esse processo se chama [treinamento](/glossario/treinamento-de-modelo/).

## Tipos principais

- **Supervisionado:** aprende com exemplos rotulados. "Estes e-mails são spam, estes não são."
- **Não supervisionado:** encontra grupos e padrões sem rótulos. Exemplo: separar clientes por comportamento de compra.
- **Por reforço:** aprende por tentativa e erro, recebendo recompensas por boas decisões.

## Exemplos práticos

- Prever quais clientes têm mais chance de cancelar.
- Estimar a demanda de produtos para planejar o estoque.
- Classificar mensagens de atendimento por assunto.
- Identificar transações fora do padrão.
- Recomendar produtos com base em compras anteriores.

## Machine learning e IA generativa

Machine learning é a base. A [IA generativa](/glossario/ia-generativa/) é uma aplicação específica dele, focada em criar conteúdo. Muitas soluções de negócio usam modelos de machine learning mais simples, que preveem ou classificam.

## Machine learning em PMEs

O ponto de partida é ter dados organizados e uma pergunta clara de negócio. Sem dados confiáveis, não há aprendizado útil. Para muitas PMEs, o primeiro passo é estruturar os dados, e só depois usar modelos.
