## Por que importa

- **Decisões:** painéis e relatórios só ajudam se os números forem confiáveis.
- **IA e automação:** sistemas de IA aprendem e respondem com base nos dados disponíveis. Dados ruins geram resultados ruins.
- **[LGPD](/glossario/lgpd/):** saber quais dados pessoais existem, onde estão e quem acessa é parte da adequação.
- **Eficiência:** menos tempo corrigindo cadastros duplicados e informações conflitantes.

## Elementos principais

1. **Responsáveis:** quem cuida de cada conjunto de dados, como clientes, produtos e financeiro.
2. **Padrões:** como cada informação deve ser registrada.
3. **Fonte oficial:** qual sistema é a referência para cada dado.
4. **Acesso:** quem pode ver e alterar o quê.
5. **Qualidade:** rotinas para encontrar e corrigir erros e duplicidades.

## Por onde começar

- Escolha um conjunto crítico, como o cadastro de clientes.
- Defina o responsável e o padrão de preenchimento.
- Limpe os dados existentes.
- Bloqueie a entrada de dados fora do padrão, com campos obrigatórios e validações.

## Governança de dados em PMEs

Em PMEs, governança não precisa ser um comitê formal. Começa com regras simples de cadastro e um responsável por cada base, o que já melhora muito a confiabilidade dos números e prepara a empresa para usar IA.
