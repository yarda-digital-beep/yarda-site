## Conceitos principais

- **Dado pessoal:** qualquer informação que identifique uma pessoa, como nome, CPF, e-mail e telefone.
- **Dado pessoal sensível:** saúde, religião, origem racial, biometria, entre outros. Exige cuidado maior.
- **Titular:** a pessoa a quem os dados se referem.
- **Tratamento:** qualquer uso do dado, de coletar a apagar.
- **Base legal:** a justificativa prevista em lei para usar o dado, como consentimento, execução de contrato ou legítimo interesse.

## Direitos dos titulares

A pessoa pode, entre outros direitos, saber quais dados a empresa tem, corrigir informações, pedir a exclusão quando cabível e revogar o consentimento.

## Primeiros passos para uma PME

1. **Mapeie os dados pessoais** que a empresa coleta e onde eles ficam.
2. **Colete só o necessário** para cada finalidade.
3. **Defina a base legal** de cada uso.
4. **Controle acessos:** cada pessoa vê só o que precisa.
5. **Tenha uma política de privacidade** clara no site.
6. **Prepare um canal** para receber pedidos dos titulares.
7. **Escolha fornecedores** que tratem os dados com segurança.

## LGPD, automação e IA

Ao automatizar processos ou usar IA com dados de clientes, os mesmos cuidados valem: finalidade clara, acesso controlado e fornecedores confiáveis. Veja [governança de dados](/glossario/governanca-de-dados/).
