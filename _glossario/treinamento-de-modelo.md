## Como funciona, em termos simples

1. **Reunir dados:** exemplos do que o modelo precisa aprender.
2. **Preparar os dados:** limpar, organizar e, em muitos casos, rotular.
3. **Treinar:** o modelo ajusta seus parâmetros para acertar os exemplos.
4. **Avaliar:** testar com exemplos que ele nunca viu.
5. **Ajustar e repetir** até o desempenho ser adequado.

## Os dados são o ponto central

Um modelo aprende o que os dados mostram, inclusive erros e vieses. Dados incompletos, desatualizados ou desequilibrados geram modelos ruins. Por isso, [governança de dados](/glossario/governanca-de-dados/) é parte essencial de qualquer projeto de IA.

## Treinar do zero, ajustar ou usar RAG

- **Treinar do zero:** caro e demorado. Faz sentido em poucos casos.
- **[Fine-tuning](/glossario/fine-tuning/):** ajustar um modelo pronto com exemplos específicos.
- **[RAG](/glossario/rag/):** não treina o modelo; dá a ele acesso aos documentos da empresa na hora de responder.

Para a maioria das empresas, usar modelos prontos com RAG e boas instruções resolve a maior parte das necessidades.

## Mitos comuns

- "A IA aprende sozinha com cada conversa." Nem sempre. Muitas ferramentas não aprendem com o uso, a menos que isso seja configurado.
- "Precisa treinar uma IA própria para usar na empresa." Na maioria dos casos, não.

## Treinamento de modelo em PMEs

Para PMEs, raramente é necessário treinar um modelo próprio. O investimento mais útil costuma ser organizar dados e documentos para que modelos prontos trabalhem bem com eles.
