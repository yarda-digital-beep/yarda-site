## Uma analogia simples

Pense num restaurante. Você não entra na cozinha para pegar o prato. Faz o pedido ao garçom, que leva até a cozinha e traz o resultado. A API é o garçom: leva o pedido de um sistema para outro e traz a resposta, seguindo regras combinadas.

## Exemplos de API no dia a dia

- O site mostra o valor do frete consultando a transportadora.
- O pagamento online é aprovado pelo sistema do banco ou da operadora.
- O formulário do site cria o contato direto no [CRM](/glossario/crm/).
- A nota fiscal é emitida a partir dos dados do pedido, sem digitação.

Em todos esses casos, sistemas diferentes conversam por API.

## Por que a API importa para sua empresa

- **Acaba com a digitação dupla.** O dado é registrado uma vez e chega a todos os sistemas.
- **Reduz erros** de cópia manual.
- **Permite automatizar processos** e usar [agentes de IA](/glossario/agente-de-ia/) que agem nos seus sistemas.
- **Dá liberdade de escolha.** Sistemas com boa API se conectam com outros com mais facilidade.

## O que perguntar antes de contratar um sistema

1. Ele tem API aberta e documentada?
2. Quais dados dá para ler e quais dá para gravar?
3. Já existem integrações prontas com as ferramentas que você usa?
4. Há custo extra para usar a API?

## API em pequenas e médias empresas

Muitos gargalos em PMEs vêm de sistemas que não conversam. Verificar a existência de API antes de contratar uma ferramenta evita retrabalho e facilita a [integração de sistemas](/glossario/integracao-de-sistemas/) no futuro.
