## Para que serve

- **Guardar informações com segurança:** clientes, pedidos, estoque, pagamentos.
- **Permitir consultas rápidas:** "quais clientes compraram nos últimos 90 dias?"
- **Manter tudo consistente:** a mesma informação, atualizada, para todos os sistemas que a usam.
- **Servir de base para análises** de [BI](/glossario/business-intelligence/) e dashboards.

## Tipos mais comuns

- **Relacional:** organiza dados em tabelas ligadas entre si, como clientes e pedidos. É o tipo mais usado em sistemas de gestão.
- **Não relacional:** guarda dados em formatos mais flexíveis, úteis para grandes volumes ou informações variadas.

## Planilha não é banco de dados

Planilhas são ótimas para análises rápidas, mas têm limites quando viram o lugar oficial dos dados: várias versões do mesmo arquivo, edição simultânea com risco de erro, falta de controle de acesso e dificuldade de integrar com outros sistemas.

## Cuidados

- **Backup:** cópias regulares e testadas.
- **Acesso:** cada pessoa vê só o que precisa.
- **Qualidade:** dados duplicados ou incompletos comprometem tudo que depende deles. Veja [governança de dados](/glossario/governanca-de-dados/).
- **Proteção de dados pessoais,** em linha com a [LGPD](/glossario/lgpd/).

## Banco de dados em PMEs

Em PMEs, os dados costumam estar espalhados em planilhas e sistemas diferentes. Centralizar o que é importante é o primeiro passo para ter números confiáveis e para usar automação e IA com segurança.
